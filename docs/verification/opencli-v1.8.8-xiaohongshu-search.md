## Adapter facts and mapping

`clis/xiaohongshu/search.js` is a read adapter using `Strategy.COOKIE`; it navigates to the Xiaohongshu search page and extracts rendered DOM cards. Classification: its source semantics are reference material only; no OpenCLI file is directly reusable as an executable Lode asset. Input/output fields need mapping, and the browser logic needs a broker-ABI rewrite. The source calls OpenCLI's `page.goto` / `page.evaluate`, builds page JavaScript strings, and owns OpenCLI-specific page recovery. Lode's accepted package contract admits only the managed script ABI and broker capabilities; direct JS/eval, CDP, shell, credentials, and private source shape are outside that boundary ([Site SKILL Package V1 at Lode baseline `b25e319f6f8b39589aaef73f74c0553e0da5c415`, lines 85-103](https://github.com/WebEnvoy/Lode/blob/b25e319f6f8b39589aaef73f74c0553e0da5c415/docs/contracts/site-skill-package-v1.md#L85-L103), [lines 294-298](https://github.com/WebEnvoy/Lode/blob/b25e319f6f8b39589aaef73f74c0553e0da5c415/docs/contracts/site-skill-package-v1.md#L294-L298)).

## Explicitly unsupported source behavior

- **Cookie export / network handoff:** the separate `xiaohongshu download` adapter reads browser cookies and passes them to the downloader ([`download.js` lines 241-252](https://github.com/jackwener/OpenCLI/blob/8271afc67e8504bda94c147f446ee29775d08274/clis/xiaohongshu/download.js#L241-L252)). Its HTTP path sets those values as a `Cookie` header on the requested media URL ([`download/index.ts` lines 121-128](https://github.com/jackwener/OpenCLI/blob/8271afc67e8504bda94c147f446ee29775d08274/src/download/index.ts#L121-L128)); it strips them on cross-host redirects ([`download/index.ts` lines 150-163](https://github.com/jackwener/OpenCLI/blob/8271afc67e8504bda94c147f446ee29775d08274/src/download/index.ts#L150-L163)). Separately, the shared media helper accepts raw browser cookies, exports them to a temporary Netscape file for `yt-dlp`, and removes the file afterward ([`media-download.ts` lines 35-42](https://github.com/jackwener/OpenCLI/blob/8271afc67e8504bda94c147f446ee29775d08274/src/download/media-download.ts#L35-L42), [lines 100-109](https://github.com/jackwener/OpenCLI/blob/8271afc67e8504bda94c147f446ee29775d08274/src/download/media-download.ts#L100-L109), [lines 171-178](https://github.com/jackwener/OpenCLI/blob/8271afc67e8504bda94c147f446ee29775d08274/src/download/media-download.ts#L171-L178)). The file writer uses owner-only permissions and the downloader spawns `yt-dlp` ([`download/index.ts` lines 229-269](https://github.com/jackwener/OpenCLI/blob/8271afc67e8504bda94c147f446ee29775d08274/src/download/index.ts#L229-L269), [lines 302-318](https://github.com/jackwener/OpenCLI/blob/8271afc67e8504bda94c147f446ee29775d08274/src/download/index.ts#L302-L318)). This is explicit credential transfer from browser context to Node network/process handling, not evidence of malicious disclosure; it remains outside Lode's broker/credential boundary and cannot be imported.
- **Raw CDP:** OpenCLI exposes a generic `cdp(method, params)` call forwarded directly to the bridge ([`cdp.ts` lines 456-457](https://github.com/jackwener/OpenCLI/blob/8271afc67e8504bda94c147f446ee29775d08274/src/browser/cdp.ts#L456-L457)). Lode/Runtime scripts cannot call raw CDP/Juggler or provider endpoints ([Site SKILL Package V1 at Lode baseline `b25e319f6f8b39589aaef73f74c0553e0da5c415`, lines 294-298](https://github.com/WebEnvoy/Lode/blob/b25e319f6f8b39589aaef73f74c0553e0da5c415/docs/contracts/site-skill-package-v1.md#L294-L298)).
- **Local process execution:** this helper example spawns the named `yt-dlp` binary and supplies extra arguments ([`download/index.ts` lines 278-318](https://github.com/jackwener/OpenCLI/blob/8271afc67e8504bda94c147f446ee29775d08274/src/download/index.ts#L278-L318)). This establishes a local child-process dependency, not that the selected search adapter runs an arbitrary command; any such process behavior is outside the site-skill broker ABI.
- **Chrome and tab/page handles:** OpenCLI's bridge manifest describes Chrome tab leases and declares debugger, tabs, cookies and `<all_urls>` permissions ([manifest lines 5-18](https://github.com/jackwener/OpenCLI/blob/8271afc67e8504bda94c147f446ee29775d08274/extension/manifest.json#L5-L18)). The adapter's collapsed-layout recovery retains and selects/closes OpenCLI `page` objects ([search.js lines 809-861](https://github.com/jackwener/OpenCLI/blob/8271afc67e8504bda94c147f446ee29775d08274/clis/xiaohongshu/search.js#L809-L861)); these host handles are not portable task refs. WebEnvoy must obtain fresh opaque observation/target refs from Harbor and reject stale refs rather than rebind them ([Site SKILL Package V1 at Lode baseline `b25e319f6f8b39589aaef73f74c0553e0da5c415`, lines 283-298](https://github.com/WebEnvoy/Lode/blob/b25e319f6f8b39589aaef73f74c0553e0da5c415/docs/contracts/site-skill-package-v1.md#L283-L298), [line 365](https://github.com/WebEnvoy/Lode/blob/b25e319f6f8b39589aaef73f74c0553e0da5c415/docs/contracts/site-skill-package-v1.md#L365)).
